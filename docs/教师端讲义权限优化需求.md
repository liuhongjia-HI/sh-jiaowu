# 新增教案功能需求

## 一、需求

在现有讲义功能之外新增“教案”。**讲义按现在的逻辑不变。**

**管理员和有权限的教师都能上传教案；无论谁上传，管理员和对应年级、学科的教师都能查看，学生不能查看。讲义保持原样。**

| 教案上传者 | 教案可见人 |
| --- | --- |
| 管理员 | 管理员、对应年级学科的教师 |
| 有权限的教师 | 管理员、对应年级学科的教师 |

其他年级或学科的教师、学生不可查看教案。

## 二、页面与权限

- 增加教案上传、列表和查看入口；上传时确定教案所属年级、学科。
- 对应年级、学科的教师查看教案；查看范围不因上传者是管理员还是教师而变化。
- 教案不出现在学生端。服务端也要限制教案详情和文件访问，防止通过链接直接打开。
- 现有讲义的上传、查看、授权、预览和下载流程保持不变。

## 三、验收

### 使用体验

- 教师的“我的讲义”和“教案”入口相邻；管理员在“教学内容”下进入教案。讲义页面不增加新的操作负担。
- 上传时只选择所属年级学科和文件。只有一个可上传范围时自动带入；选择多份文件时按文件名生成各自标题，也可逐份修改。
- 列表提供标题/文件名搜索、年级学科筛选，并显示上传人、时间和预览状态。预览转换中自动刷新状态；转换失败可在有上传权限时重新生成预览。
- 批量上传出现个别失败时，保留失败文件及原因，可直接重试；已上传文件不会重复提交。

### 权限与回归

1. 管理员上传五年级英语教案后，管理员和五年级英语教师可见。
2. 有权限的教师上传五年级英语教案后，管理员和五年级英语教师可见。
3. 其他年级或学科的教师、学生看不到上述教案；直接访问教案链接也无法读取。
4. 原有讲义功能按当前逻辑正常使用。

目标：国庆前完成迭代。
