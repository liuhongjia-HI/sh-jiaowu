# Starline 会议优化实施记录

已完成本地代码及相关验证，尚未提交、推送或部署。网页自动化使用模拟接口；后端检查为本地 store/router 测试，不代表生产数据库、公众号收件或小程序真机验收。

## 本轮完成

| 需求 | 实施结果 |
| --- | --- |
| 1、2 目录同步 | 编辑目录时可勾选实际配置的目标课程；提供整套目录及单 Unit 入口。保存源目录后自动预览，确认再同步。单 Unit 包含下级 Chapter、Lesson；沿用现有合并、权限及版本校验，保留目标独有目录和资料。未增加覆盖删除规则。 |
| 3、4 教案浏览 | 教案按课程或既有共享系列组织，展示阶段、班型和数量；页头用浅蓝标识。历史无课程关联的教案保留入口；进入课程及刷新保留选择。文件与讲义独立。 |
| 5 教案上传 | 保留课程归属，章节选填，默认留空；支持整批和逐文件章节，以及明确不关联章节。可一次上传多份，仅重试失败文件；后端同步支持课程通用教案及其目录引用校验。 |
| 6、7 已明确的筛选和文案 | 课程与教案采用年级、学科、学习阶段点选标签；阶段显示紧凑编码。筛选、搜索和返回位置沿用现有状态保存。学年未接入。 |
| 10、11 家长学生批量下载 | 已按后续确认实施课程入口、选择文件、异步任务、复制电脑领取链接及小程序扫码确认，详见[专项实施记录](家长学生批量下载实施记录_2026-10-07.md)。尚未完成线上和真机验收。 |
| 8、9 教师表格 | 常用编辑、密码操作与姓名固定在左；随后为资料查阅范围、授课范围、可上传内容、可批改。手机号等信息保留，停用及删除置于最后。横向滚动检查通过，账号及权限规则沿用原逻辑。 |
