# 小程序学生端 — 当前状态与剩余待办

> 基于 2026-06-12 代码梳理。原清单中的真实微信登录、成长轨迹、徽章墙、收藏、真实课程进度、真实任务状态和结果页真实反馈已完成，不再作为待办项。

## 已完成的核心链路

| 模块 | 当前状态 |
|---|---|
| 登录与绑定 | 小程序调用 `wx.login()`；生产环境后端使用 `WECHAT_APPID`、`WECHAT_SECRET` 走 `jscode2session`，演示环境保留账号密码登录。手机号授权通过 `phoneCode` 交给后端解析并绑定。 |
| 学习首页 / 学习页 | 课程进度来自后端 `progress` / `continueProgress`，不再由前端造假。 |
| 小挑战 | 题目详情、作答提交、自动判分、结果页分数 / 评语 / 奖励均接真实接口。 |
| 成长轨迹 | `GET /api/student/growth` 返回提交记录和已学资料，按时间倒序展示。 |
| 徽章墙 | `GET /api/student/badges` 按学习数据派生获得状态。 |
| 收藏 | 支持学习资料和小挑战收藏、取消收藏、收藏列表。 |
| 可上课时间 | 学生可维护可上课时间，并查看已确认课表。 |

## 上线前外部配置清单

这些事项不属于本地代码能直接完成的范围，但会影响生产可用性。完成后请同步更新管理后台“系统设置”和“上线配置检查”。

| 步骤 | 操作 | 完成标准 |
|---|---|---|
| 1 | 配置生产接口域名 | `productionApiDomain` 为 HTTPS 正式域名，不使用 `localhost` 或 `127.0.0.1`。 |
| 2 | 配置小程序合法域名 | 微信公众平台的 `request` 与 `downloadFile` 合法域名均包含 `https://gate.starlineeducation.com.cn`，域名已备案且可访问 `/api/health`。 |
| 3 | 关联微信公众号 | 小程序主体和公众号完成关联，公众号可用于课程提醒、练习发布、批改完成等触达。 |
| 4 | 申请并配置模板消息 | 公众号后台模板审核通过，后端配置 `WECHAT_OFFICIAL_ACCOUNT_APPID`、`WECHAT_OFFICIAL_ACCOUNT_SECRET`、`WECHAT_OFFICIAL_ACCOUNT_TEMPLATE_ID`。 |
| 5 | 补齐学生公众号 openid | 已开通套餐学生档案中 `officialAccountOpenId` 覆盖率满足运营要求。 |
| 6 | 验证补发链路 | 人为制造一条 `待配置` 或 `发送失败` 的公众号通知，补齐配置后在后台通知页点击“补发”并确认状态变为 `已发送`。 |
| 7 | 真机验证文件预览 | 在微信开发者工具和至少一台真机上验证 PDF / Word / PPT 资料预览或下载体验。 |

完整业务验收项见 [教育小程序后台最佳实践验收表](./教育小程序后台最佳实践验收表.md)。

## 评审建议

- 微信开发者工具演示使用真实微信登录和手机号授权绑定；需先启动本地后端并配置 `WECHAT_APPID`、`WECHAT_SECRET`，再用后台学生档案匹配手机号完成绑定。
- 管理后台使用教师或管理员账号，可演示上传学习资料 / 题目、排课、批改反馈、学生开通和权限核对。
- 真实登录评审需要提前配置 `WECHAT_APPID`、`WECHAT_SECRET`；小程序 `app.js` 默认保持 `useRealWechatLogin=true`。
